# 绘图、动作与时间分层

## 1. 绘图层：画什么

小网格中的整数坐标、多边形和矩形足以画出人物、车辆、金币、设备。先定轮廓与关节，再加有限的明暗色块。网格尺度按对象分别设置；人物轮廓可以很粗，背景窗口可以很细，不需要把整个画面强制降到同一低分辨率。

绘图函数不读取时间或全局播放状态。输入形状参数，输出像素，例如 `person(ctx, {x, y, unit, facing, expression, pose})`。锚点固定在脚底、手部或车辆中心，使碰撞、接触和缩放可预测。

截图可以用于观察和量测。要求代码重建时，成片绘图不能把原片截图或裁切角色直接当作新素材，并声称全部重绘。

放大位图或小画布时关闭图像平滑。文字可使用正式像素字体。需要硬边描边时，先把单色字形 alpha 二值化，重新着色，再叠加外边、内边和填充；只改 alpha、不修正半透明边缘 RGB，会把灰色杂边放大。字体先加载完成再缓存字形。

光晕、阴影和闪光可以连续、柔和。像素轮廓和光学效果不必共享一种采样方式。若参考有中心亮、边缘暗的白闪，单层均匀白色遮罩只能近似，需另用径向渐变拟合。

## 2. 动作层：怎么动

- 平移入场：整体 x/y 改变，不能当作行走。行走同时需要脚相对地面的支撑关系、交替步态和有限躯干起伏。
- 跳跃：短暂预备、腾空轨迹、落地接触、收稳。影子跟随地面而不是角色一起飞走。
- 拿取 / 放置：手先到达道具，道具的归属在接触点切换，之后跟随对应锚点。
- 表情：眼、眉、嘴可以离散换形，不必生成整个人物的新图片。
- 冲击：快速过冲、回落、结果保持。数字从大缩回不等于从零计数。
- 粒子：每个粒子的出生时间、初速度、旋转和寿命由固定种子确定。由 `t - birth` 直接计算位置与透明度，不依赖前一帧积分。
- 透视逼近：单个正面物体的非线性尺度变化可能已足够。用背景是否同步放大来区分物体运动与镜头推进。

对每个动作写出准备、发生、收稳、保持四个阶段；不是四段都必须明显出现，但不能遗漏关键的接触或结果。

## 3. 时间层：何时动

每帧从绝对时间计算：`state = sample(t)`，`draw(state)`。先清空画布并重置变换/透明度，再绘制该帧；绘图函数使用成对的 save/restore。

事件边界优先存为帧号，或用 `frame / fps` 表示。不要假定按顺序播放；渲染器、预览拖动和并行渲染都可能先请求第 180 帧，再请求第 30 帧。

关键帧控制位置、尺寸、透明度或颜色。缓动用于描述速度，不是默认添加弹簧。用于复刻时，分段采样往往比随意挑选一个 easing 更接近原片。

分组和遮罩要明确“谁属于谁”：面板退场时，文字、边框和装饰分别随哪个面板移动；字幕通常位于场景组外。透明效果出现不代表旧场景已经结束。

## 模板接口

`assets/starter/` 提供：

- `config.json`：画幅、时长、fps、标题。
- `src/pixel.js`：绘图原语、角色、道具与工厂。
- `src/motion.js`：绝对时间采样和动作曲线。
- `src/film.js`：语义事件与分层绘制。
- `window.renderAt(t, mime, quality)`：返回当前帧的 data URL。
- `window.ready`：字体与配置加载完成。

新文案主要重写事件与场景；模板里的 6 秒不是通用时长。迁移到其他渲染框架时保留 `sample(t)` 和绘图接口，替换外层导出连接。
